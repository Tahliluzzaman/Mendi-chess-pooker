Mendi Chess Arena — Offline Edition (separate JavaScript file)

Files:
- index.html: page layout and styling
- app.js: embedded chess rules library and game logic
- README.txt: these instructions

IMPORTANT:
1. Extract all three files into the SAME folder.
2. In Acode, open this folder and open index.html.
3. Preview index.html. Do not preview app.js directly.
4. If an older version is open, close the old preview and open this index.html again.
5. The Elo selector (400–2000) should appear under Game Settings.

Features:
- Offline chessboard and legal moves
- New Game, Undo, Flip Board
- Vs Computer / Two Players
- Elo difficulty choices from 400 to 2000 (approximate targets, not official ratings)
- Built-in small search engine; not Stockfish, and strength is not certified

If you still see only “Play mode” and “Your side” with no Elo selector, you are viewing an older/different index.html file. Replace that old file with the index.html from this package and keep app.js beside it.
